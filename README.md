# FSGS-
FSGS 肾病综合征 急性肾衰竭
49岁，中年女性，因“反复双下肢水肿8年余，再发半月”入院
患者于7年余前(2017-11-27)因"感冒"后出现颜面，双下肢水肿，伴有尿量减少，就诊于中山大学附属第一医院，查24小时尿蛋白定量20g，血清白蛋白不详，诊断"肾病综合征",2018-01-11行肾脏穿刺活检，病理提示：FSGS(细胞型)伴急性肾小管损伤，予血液透析，口服"强的松60mgqm"及对症治疗后好转，出院后门诊随访并逐渐减量强的松，激素减量至15-20mg时水肿缓解。后患者水肿反复，多次于中山大学附属第一医院予激素，血液透析等治疗。2019-06-10至2020-10-01已予环磷酰胺冲击治疗7次，累积5.2g，期间同时口服"强的松10mg/日"，但仍有反复水肿。2022-11-20因"双下肢水肿加重"再次就诊于中山大学附属第一医院，查24小时尿蛋白定量8.3g，诊断"1。肾病综合征(FSGS):2。肾性高血压：3。类固醇性糖尿病：4。继发性甲状腺功能减退症；5。甲状腺功能亢进症(碘131治疗后)"，予"强的松10mg/日，环磷酰胺0.8g冲击"。后患者于2022-12-22/12-23,2023-02-07/02-08,2023-03-07/03-08,2023-04-07/04-08在我科住院分别予"环磷酰胺0.4g/0.4g"冲击治疗，"环磷酰胺"累积剂量为9.2g.2023年5月在我院住院查尿蛋白定量10880mg/24h(24小时尿量：800ml)，考虑治疗效果差，建议完善基因检测，但患者不同意，开始使用激素2片qd+环孢素75mg bid。于2024-5-16加入CKDMIP，蛋白尿转阴，激素减量至2片qd+环孢素25mg bid。定期门诊复诊，2025.04.23复查尿蛋白定量3630mg/24h(24小时尿量1000ml），激素加量至4片qd+环孢素25mgbid。后遵医嘱激素减量至12mg。于2025.8.11复查尿蛋白定量：2051.92mg(24h尿量：800ml)，考虑病情复发，08-15调整为"环孢素75mg bid+甲泼尼龙8mg qd"治疗。2026.1.20蛋白尿转阴，调整为"环孢素50mg bid+甲泼尼龙4mg qd"。半月前患者再发颜面部水肿，无气促，无夜间阵发性呼吸困难，偶有腹胀，腹痛，伴有咳嗽，咳少量白色粘痰，伴有反酸，恶心，无胸痛，无腹泻，无呕吐，无解黑便，血便，无畏寒，发热，遂来我院门诊就诊，为进一步治疗，拟"肾病综合征"收入我科。近1周患者精神一般，睡眠，食欲欠佳，大便正常，体重改变不详。
既往有"肾性高血压"8年，最高血玉160/90mmHg，平素口服"厄贝沙坦0.15g qd"降压治疗。有"类固醇性糖尿病"8年，自诉空腹血糖正常，现口服拜糖平，药物规格不详。7年前因"甲状腺功能亢进症"行碘131治疗，后诊断"继发性甲状腺功能减退症"，目前口服"优甲乐150ugqd".2023-05因左上肢肿胀疼痛在我院介入外科住院，诊断左侧锁骨下静脉，左侧颈内静脉血栓形成，自诉规律服用利伐沙班抗凝治疗3月，定期门诊复查，好转后停药。有"慢性浅表性胃炎伴糜烂(胃窦)，内痔，胃底腺息肉(已钳除)，盲肠增生性息肉(已钳除)，盲肠管状腺瘤(已钳除)，升结肠管状-绒毛状腺瘤(已钳除)"病史，2019年因"子宫肌瘤"行"子宫肌瘤切除术"。否认高血压，糖尿病，冠心病等慢性病史，
诊断：1。急性肾衰竭肾病综合征伴局灶更化性肾小球肾炎；2。类固醇性糖尿病；3。甲状腺功能亢进症(碘131治疗后);4。继发性甲状腺功能减退症；5。慢性浅表性胃炎伴糜烂(胃窦):6.高尿酸血症：7。急性咽炎，鼻炎；8。胆囊结石；9。胸腔积液：10。支原体感染：11。低钾血症。
